Política de Privacidad de burrnny lectura

Última actualización: 8 de octubre de 2026

burrnny lectura es una herramienta personal de línea de comandos que usa el propietario del canal de YouTube @Burrnny para consultar las estadísticas de ese canal. No es una app pública y no la usa nadie más.

1. Qué datos lee

Usa los Servicios de API de YouTube (YouTube Data API v3, YouTube Analytics API y YouTube Reporting API) con permisos de solo lectura (youtube.readonly y yt-analytics.readonly) para leer, del canal del propio usuario:

  • Datos de los vídeos: título, fecha, duración, privacidad y contadores públicos.
  • Estadísticas: vistas, tiempo de reproducción, fuentes de tráfico, retención y suscriptores ganados.
  • Informes de alcance: impresiones y porcentaje de clics.

No sube, edita, borra ni comenta nada, y no lee datos de otras cuentas.

2. Dónde se guardan

  • Los datos y el token de acceso se guardan solo en la computadora del propietario, en archivos locales con acceso restringido.
  • No hay servidor ni base de datos externa.
  • Los datos no se venden, no se usan para publicidad y no se comparten con terceros, salvo con las herramientas que el propio usuario elija para analizar su canal.

3. Servicios de Google

Al usar esta herramienta se aplican las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

4. Cómo retirar el acceso

El acceso se puede revocar en cualquier momento desde la página de permisos de la cuenta de Google: myaccount.google.com/permissions. Al revocarlo, la herramienta deja de poder leer datos.
